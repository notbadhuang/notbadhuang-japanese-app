# 正能日语

正能日语是一款电脑端日语学习应用，提供从零基础到 N5 的课程、音频、练习与测试。学习记录保存在本机。

## 当前版本：0.1.4

[下载 Mac 或 Windows 安装包](https://github.com/notbadhuang/notbadhuang-japanese-app/releases/tag/v0.1.4)

Mac 适用于 M 系列芯片、macOS 15 及以上；Windows 适用于 64 位电脑。

## 安装与更新

打开安装包，按说明操作。升级前退出 App，安装后选择原来的学习记录即可继续。

首次安装可能出现系统安全提示：Mac 可在「系统设置 → 隐私与安全性」中允许打开；Windows 可能显示发行者未知。

## 使用反馈

可通过原社群反馈使用问题，说明应用版本、系统版本和遇到问题的操作步骤。
